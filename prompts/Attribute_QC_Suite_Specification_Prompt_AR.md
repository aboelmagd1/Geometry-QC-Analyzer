# المواصفات الفنية الشاملة وبرومت تطوير منظومة فحص البيانات الوصفية (Attribute QC Suite)

> **نوع الوثيقة:** مواصفات معمارية وبرومت تنفيذ برمجي (System Architecture & Developer Prompt)
> **البيئة المستهدفة:** ArcGIS Pro 3.x SDK (.NET 8.0-windows / C# 12 / WPF)
> **حالة الوثيقة:** نسخة نهائية معتمدة للتنفيذ - الإصدار المخصص (Custom Build - 6 Rules)
> **التاريخ:** 30 أكتوبر 2026

---

## 📌 1. الهدف والرؤية العامة للمشروع

تطوير إضافة **Geometry QC Analyzer** لتصبح منصة متكاملة لفحص الجودة المكانية والوصفية معاً:

1. **الفحوصات الهندسية (Geometry QC):** الفحوصات الحالية لمضلعات الأراضي (11 فحصاً).
2. **فحص البيانات الوصفية (Attribute QC):** محرك متقدم للتحقق من صحة الجداول، وتطبيق مجموعة مختارة ومحددة من القواعد الحقلية (6 Field Rules)، ومطابقة البيانات مع جداول الجيوداتابيز أو ملفات **Excel** المرجعية الخارجية بمرونة وأداء فائق يدعم الـ Feature Services دون قفل الملفات.

---

## 🔒 2. القواعد العامة والأمان المعماري (Architectural Guardrails)

1. **السرعة هي الأولوية القصوى (Zero Geometry Processing):**
   * يُمنع منعاً باتاً استدعاء، أو قراءة، أو معالجة أي أشكال هندسية (`Geometry`) أو استخدام `GeometryEngine` أثناء فحص البيانات الوصفية (Attribute QC).
   * الفحص يقتصر 100% على الحقول النصية والرقمية (Attributes) فقط.
2. **أمان القراءة فقط 100% (Strict Read-Only):**
   * لا يتم فتح `EditOperation`، ولا تعديل بيانات الطبقات المصدرية، ولا كتابة أي بيانات على الجداول المرجعية أو ملفات Excel.
3. **قراءة Excel بوضع المشاركة غير المقفلة (`FileShare.ReadWrite`):**
   * استخدام مكتبة **`ExcelDataReader`** مع قراءة الملف عبر تيار مشترك ليعمل حتى لو كان الملف مفتوحاً وقيد التعديل في Microsoft Excel.
   * **ملاحظة لبيئة .NET 8:** يجب تسجيل مزود الترميز `System.Text.Encoding.RegisterProvider(System.Text.CodePagesEncodingProvider.Instance);` لضمان قراءة ترميز ملفات الإكسيل بدقة.
4. **عزل الأخطاء (Fault Isolation):**
   * كل قاعدة وكل صف يُفحص داخل نطاق `try/catch` معزول لتجنب انهيار الفحص بالكامل في حال وجود قيم تالفة.
5. **تزامن المسارات (Threading & Responsiveness):**
   * كافة استعلامات البيانات تتم داخل `QueuedTask.Run`، مع ربطها بـ `CancellationToken` لضمان الإلغاء الفوري دون تعليق واجهة المستخدم.

## ⚙️ 3. آلية التشغيل واختيار الطبقة المستهدفة

* **خيارات التشغيل:** يتم التحكم بتشغيل (Geometry QC) أو (Attribute QC) أو كلاهما عبر خيارات مستقلة (Checkboxes).
* **الوضع الافتراضي:** يكون الفحص الهندسي (Geometry QC) هو المُفعل افتراضياً، إلا إذا تم تغيير الإعدادات من قِبل المستخدم
* **اشتراط الطبقة لفحص الأتريبيوت:**
* * يتطلب فحص الأتريبيوت اختيار طبقة محددة (`Target Layer`)، سواء كانت Local Feature Class أو **Web Feature Service**.
  * إذا تم تفعيل فحص الأتريبيوت وكان الاختيار هو "All Polygon Layers" أو لم يتم اختيار طبقة، يتوقف فحص الأتريبيوت مع إظهار رسالة:
    `"Please select a target layer from Contents / يرجى تحديد طبقة مستهدفة من محتويات الخريطة."`
* **احترام التصفية (Definition Query):**

  * المحرك يقرأ ويعالج البيانات من الطبقة استناداً لأي استعلام تصفية (`Definition Query`) مطبق حالياً على الطبقة في الخريطة.

## 🖥️ 4. محرر قواعد الأتريبيوت (Attribute Rules Editor)

يتم فتح محرر القواعد في **نافذة WPF مستقلة (Dialog Window)** لتوفير مساحة أفقية مريحة لضبط القواعد والمقارنات المرجعية.

### ميزات المحرر والحفظ الذكي:

1. **استعراض الحقول:** عرض اسم الحقل (Name)، والاسم المستعار (Alias)، والنوع (Type)، واختيار القواعد المناسبة لكل حقل.
2. **الحفظ الذكي وبصمة المخطط (Schema Signatures):**
   * لا تُربط القواعد باسم الطبقة فقط، بل بـ **هيكل الحقول (Schema Signature)**.
   * **التعرف التلقائي:** عند اختيار طبقة جديدة لها نفس أسماء وأنواع الحقول لطبقة تم إعدادها مسبقاً، يقوم المحرك بتحميل القواعد تلقائياً.
3. **قوالب القواعد (Rule Profiles):** إمكانية حفظ واستيراد وتصدير إعدادات القواعد بصيغة JSON لنقلها بين المشاريع المختلفة.
4. **المرونة مع تغير المخطط (Schema Drift):** تخطي الحقول المحذوفة بسلاسة مع تسجيل تحذير `field missing` دون توقف البرنامج.

## 📋 5. قائمة القواعد الحقلية المعتمدة (The 6 Target Field Rules)

يقتصر نطاق الفحص على القواعد الـ 6 التالية فقط لتلبية المتطلبات الدقيقة للمشروع:

| كود القاعدة | اسم القاعدة                  | الوصف وشروط التحقق                                                                                                |
| :-------------------: | :------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------- |
|     **R1**     | **Not Null / Not Empty**         | الحقل غير فارغ، والمسافات البيضاء فقط (Whitespace) تُعد فارغة.                           |
|     **R2**     | **No Leading / Trailing Spaces** | منع المسافات الزائدة في بداية النص أو نهايته.                                                |
|     **R3**     | **Unique Value**                 | القيمة فريدة تماماً عبر السجلات التي يشملها الفحص ضمن التصفية الحالية. |
|     **R4**     | **Constant / Uniform Value**     | جميع المعالم المفحوصة تحمل نفس القيمة تماماً.                                               |
|     **R5**     | **Not Placeholder Value**        | منع القيم البديلة الوهمية (`N/A`, `NULL`, `none`, `-`, `0`, `unknown`).                         |
|     **R6**     | **Cross-Field Equality**         | مطابقة قيمة الحقل مع حقل آخر في نفس السجل (Field A == Field B).                                  |

## 📊 6. محرك المقارنة مع الجداول المرجعية (Reference Tables Comparison)

### 1) المطابقة والقيم الخام (Raw Values for Feature Services):

* لضمان التوافق التام مع طبقات الـ (Services) وقواعد البيانات المشتركة، يقرأ المحرك **القيمة الخام (Raw Code)** المخزنة في الطبقة ويقارنها مباشرة بالمرجع الخارجي دون تحويل أو اعتماد على توصيفات الـ Domains.

### 2) مقارنة الحقول (Field Comparisons):

1. **النصوص والتواريخ:** تطابق نصي مباشر بعد توحيد المسافات (Trim).
2. **الأرقام والمساحات والأطوال (قراءة القيم الوصفية المخزنة فقط):**
   * **لا توجد حسابات هندسية:** يكتفي المحرك بقراءة القيمة الرقمية المخزنة فعلياً داخل حقل الطبقة (مثل `Shape_Area` أو أي حقل Attribute) ومقارنتها بالقيمة المرجعية في الإكسيل.
   * **تفعيل السماحية (Tolerance %):** يظهر خيار لتحديد نسبة سماحية (القيمة الافتراضية **`1.0%`**).
   * **معادلة حساب الاختلاف النسبي (Relative Difference Formula):**
     $$
     \text{Difference (\%)} = \left( \frac{|V_{\text{Layer}} - V_{\text{Ref}}|}{|V_{\text{Ref}}|} \right) \times 100
     $$
   * **شرط الأمان للصفر:** إذا كانت $V_{\text{Ref}} = 0$، يجب أن تكون $V_{\text{Layer}} = 0$، وإلا يُسجل خطأ.

## 🚀 7. الأداء الفائق والتعامل مع البيانات الضخمة (High Performance)

1. **الذاكرة المؤقتة (In-Memory Caching):**
   * قراءة جدول Excel/GDB **مرة واحدة فقط** في بداية الفحص وتخزينه في `Dictionary<string, Dictionary<string, object>>` للبحث اللحظي $O(1)$.
2. **الاستعلام الأمثل (Optimized SubFields without Geometry - القاعدة الذهبية للأداء):**
   * يجب استرجاع الحقول الوصفية المطلوبة فقط عبر `SearchCursor`:
     ```csharp
     var queryFilter = new QueryFilter { SubFields = "OBJECTID, " + string.Join(", ", requiredFields) };
     ```
   * **المنع المطلق لجلب الـ Shape:** يُمنع تماماً تضمين حقل الـ Geometry (`Shape`) في هذا الاستعلام لتفادي سحب مئات الميجابايت عبر الشبكة في طبقات الـ Services.

## 🧭 8. عرض النتائج والاحتفاظ بالأخطاء على الخريطة

1. **شجرة النتائج (Results DockPane):**
   * عرض الأخطاء مقسمة حسب القاعدة والحقل مع عرض رقم الـ (OID) والقيم الفعلية والمرجعية ونسبة الفرق.
   * زر **Zoom** للانتقال وتحديد المعلم في الخريطة مباشرة.
   * قسم خاص بـ **(Orphan Keys)** لعرض السجلات الموجودة في الإكسيل والتي لا يوجد لها مقابل في الطبقة.
2. **طبقة أخطاء مستقلة (Error Layer Generation):**
   * **التنفيذ المعزول:** بعد اكتمال عملية الفحص الوصفي السريعة بالكامل، تنشئ الأداة استعلاماً جديداً ومنفصلاً يجلب الـ `Shape` للمعالم الخاطئة فقط (بناءً على أرقام `OID` التي فشلت في الفحص).
   * تُنشأ طبقة `Attribute_Errors_Log` تُضاف لمحتويات الخريطة (Contents) بترميز لوني مميز.
3. **حالة النجاح:** رسالة واضحة `"No attribute errors found ✓"` في رأس النتائج.
